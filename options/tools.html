    Limit test (development install only)

    Saves this many bookmarks to the Diigo account you're signed in with, one after the other, as the bookmark form saves them: private, at https://example.com/swift-limit-test/<n>, with the tag swift-limit-test. The numbers go on where the last run stopped (kept per account in this browser), so each one is a new bookmark. It stops at the first one Diigo doesn't save and shows what Diigo answered. Delete them afterwards in the Swift Library: search for the tag, Bulk edit, Delete.
